## 2. Scientific methods

Exactly four governed methods are evaluated per condition, in fixed order:

1. `scsv-elrc-v11-full` — frozen v11 comparator;
2. `scr-only` — SCR shared core + frozen v11 localized path;
3. `ncee-only` — frozen v11 shared core + NCEE localized path;

No external baseline is part of the Phase-3C GO/NO-GO gate. PySR, Operon, FSL-GEP, NRSR, multitask SR, independent symbolic families, and real-world data belong to a later external-validation suite after the internal development decision is frozen.

## 3. Dataset and condition matrix

The primary dataset is the frozen V10 synthetic federated symbolic benchmark generated by `scsv_v10_benchmarks.py`.

- `quadratic_role_v10`, `linear_role_v10`, `trig_role_v10`, `interaction_role_v10`: `K∈{4,8,16}`, balanced/imbalanced, single role for all K, quarter role for K∈{8,16}, noise `0.10/0.30` → 20 conditions per family, 80 total;
