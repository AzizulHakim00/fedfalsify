# FedFalsify Phase 3 Design v2: Sequential Noise-Calibrated Scope Certification

**Status:** Candidate final design, pending human review before implementation  
**Working method name:** **FedFalsify v12: Set-Conditional Structural Verification with Noise-Calibrated Scope Certification (SCSV-NCSC)**  
**Base scientific source:** `e58ff85a93a7498a6220a3032d153c02290de352`  
**Design branch:** `research/phase3-noise-calibrated-scope-certification`  
**Date:** 2026-09-06

## 1. Purpose

Phase 3 is a new scientific generation, not a PQCR-v3 repair. Phase 1 and Phase 2 established that post-quarantine coefficient refitting can occasionally expose true conditional structure, but replacing or augmenting the v11 reference does not solve the dominant structural-recovery ceiling. DR-PQCR-v2 restored v11-level exact recovery but produced no net exact-recovery gain.

The new design targets the two dominant frozen failure mechanisms:

1. high-noise loss of power in localized/deviation certification; and
2. high-noise errors in ordinary/shared structure that v11 treats as immutable.

The scientific target is a federated symbolic model with two explicitly separated structural layers:

- a **shared symbolic core** supported broadly across clients; and
- sparse **client-localized symbolic deviations** supported only on a certified client subset.

The method uses additive client sufficient statistics and does not require raw rows at the server. This is a data-local computation property, not a differential-privacy or cryptographic privacy claim.

## 2. Frozen evidence motivating Phase 3

The redesign is grounded in sealed Phase-1/Phase-2 evidence. It is not a threshold adjustment made to rescue a failed gate.

Phase-2 v11 facts:

- exact recovery: `0.8300`;
- deviation TP/FP/FN: `461/1/59`;
- all `59/59` true-deviation misses occurred at noise ratio `0.30`;
- `56/59` missed true deviations were already in the high-recall candidate bank;
- missed true deviations decomposed into `26` effect-role localization failures, `25` pooled-evidence failures, and `8` outside-role failures;
- among `102` non-exact conditions, `88` contained a shared/core error;
- `46` were shared/core-only failures;
- `87/88` shared/core-error conditions occurred at noise ratio `0.30`.

Phase-2 DR-PQCR-v2 facts:

- exact recovery: `0.8300`, identical to v11;
- exact gain over v11: `0.0000` on each Phase-2 seed;
- only three PQCR-only rescues occurred;
- one rescue was structurally true and two were structurally false.

These observations imply that candidate generation is already high recall. The primary bottleneck is **structural evidence and scope classification under high noise**.

## 3. Research question

Given federated clients generated by related but non-identical symbolic mechanisms, can a method recover:

1. the common/shared symbolic structure;
2. sparse localized deviations;
3. the client subset supporting each localized deviation;

while preserving strong false-structure control, null safety, and outside-role non-degradation as observation noise increases?

## 4. Primary hypothesis

> **H3:** A sequential Discovery -> Selector -> Probe architecture that uses noise-scaled partial nested-model evidence, independent shared-core certification, and final Holm-controlled Probe testing will improve high-noise exact structural recovery over v11 without materially increasing false shared or localized structure.

The design has two separable scientific mechanisms:

- **SCR:** Shared-Core Re-certification.
- **NCEE:** Noise-Calibrated Effect Evidence for localized deviations.

The full method is `SCR + NCEE` and both mechanisms must be independently ablated.

## 5. Non-goals and claim boundaries

Phase 3 will not:

- retune PQCR-v1 or DR-PQCR-v2;
- change v11's existing thresholds on spent Phase-1/Phase-2 evidence;
- reuse `29101--29105` or `29201--29205` for method selection;
- touch reserved final-confirmation seeds `11001+`;
- claim differential privacy, secure aggregation, or cryptographic confidentiality;
- claim causal interpretation of client roles;
- claim to be the first federated symbolic-regression method;
- expand the benchmark grammar merely to raise recovery;
- use benchmark truth or test outcomes to select terms or coefficients;
- alter the final Phase-3 method after fresh development outcomes are inspected.

PQCR-v1 and DR-PQCR-v2 remain frozen historical ablations.

## 6. Structural model

For client `k` and observation `i`, Phase 3 assumes the benchmark-level decomposition

`y_ki = f_0(x_ki) + sum_m z_km * delta_m * phi_m(x_ki) + epsilon_ki`,

where:

- `f_0` is a shared symbolic mechanism;
- `phi_m` is a declared localized candidate;
- `z_km in {0,1}` indicates membership of client `k` in localized role `m`;
- `delta_m` is the role-common coefficient for localized mechanism `m`;
- `epsilon_ki` is observation noise.

For the frozen synthetic development benchmark, noise is homoskedastic Gaussian within each generated condition because the generator applies one pooled noise standard deviation to all clients. Classical F-test calibration is therefore aligned with the benchmark data-generating mechanism. External/real-data validation must treat homoskedastic Gaussian calibration as an assumption and report robustness analyses separately.

## 7. Sequential data-use architecture

The existing deterministic partitioning is retained, but each split receives one explicit scientific role.

### 7.1 Discovery D

Discovery is used for:

- the frozen v6 high-recall bank and candidate nomination;
- ordinary/shared candidate nomination;
- localized candidate nomination and provenance;
- exploratory noise-calibrated client-role construction after Selector has certified the shared structure.

Discovery never supplies a final structural p-value.

### 7.2 Selector S

Selector is used for:

- independent shared-core certification from the Discovery-nominated ordinary candidate family;
- non-final localized-role screening after Discovery constructs a candidate role;
- discovery-sign confirmation;
- median role benefit;
- selector outside-role non-degradation;
- structural/rank/estimability checks.

Selector outcomes may refine which localized hypotheses are sent to Probe, but they do not provide the final localized structural p-value.

### 7.3 Probe P

Probe is reserved for the final localized structural hypothesis test.

By the time Probe is accessed, all of the following are frozen:

- shared structure;
- localized candidate term;
- localized role client IDs;
- outside-role client IDs;
- expected localized effect sign;
- candidate family to be multiplicity corrected.

Probe performs a proper partial nested-model test and Holm correction. No Probe outcome may change role membership or introduce a new candidate.

## 8. Federated sufficient-statistic foundation

For a client design matrix `X` and response `y`, define the packet components

- `G = X^T X`;
- `h = X^T y`;
- `q = y^T y`;
- `n = number of observations`.

These quantities add across clients:

- `G_S = sum_k G_k`;
- `h_S = sum_k h_k`;
- `q_S = sum_k q_k`;
- `n_S = sum_k n_k`.

For a fixed ordered term set `T`, least-squares coefficients and SSE can be reconstructed from the aggregate packet without raw rows.

The implementation must use deterministic catalog ordering and a deterministic rank-revealing solver.

## 9. Partial nested-model structural test

The primary structural evidence primitive is a one-degree-of-freedom partial nested-model F test, not the v11 raw fold-vote rule and not the old pooled-delta threshold.

For a fixed scope and a fixed shared basis `X_S`, compare:

- REDUCED: `y = X_S beta + epsilon`;
- FULL: `y = X_S beta + z delta + epsilon`,

where `z` is the tested candidate column.

Both models re-estimate nuisance shared coefficients on the evaluation partition. Let `SSE_R` and `SSE_F` be the minimized reduced/full SSE values, and let `p_F` be the effective full-model rank. Then

`F = ((SSE_R - SSE_F) / 1) / (SSE_F / (N - p_F))`.

The upper-tail probability under `F(1, N - p_F)` is the structural p-value when:

- FULL has exactly one additional identifiable degree of freedom;
- residual degrees of freedom are positive;
- the rank convention is deterministic;
- the benchmark Gaussian-noise assumptions hold.

If the tested candidate does not increase effective rank by exactly one, the hypothesis is classified `STRUCTURAL-RANK-AMBIGUOUS` and cannot be accepted.

This partial test is preferred to testing a deviation against frozen numerical shared coefficients because it separates candidate-specific structural evidence from nuisance coefficient error.

## 10. Rank and numerical policy

### 10.1 Rank

Use a deterministic rank-revealing QR or SVD convention with one globally defined numerical rank tolerance derived from matrix scale and machine precision. The tolerance is an engineering/numerical rule, not a scientific tuning parameter.

Do not use tuned ridge regularization to force full rank for inferential tests.

### 10.2 Abstention

If a candidate is non-identifiable, nearly collinear under the fixed rank rule, or leaves non-positive residual degrees of freedom, the method abstains with an explicit diagnostic rather than inventing significance.

### 10.3 SSE tolerance

The predecessor outside-role safety tolerance is preserved exactly: FULL is outside-safe when

`SSE_FULL <= SSE_REDUCED + 1e-10`.

The tolerance is inherited from the frozen v8/v11 safety path and is not re-tuned.

## 11. Multiple-testing policy

Final structural claims use family-wise error control because the candidate families are small and structural false positives are costly.

### 11.1 Shared/core certification

Apply **Holm step-down correction at alpha_shared = 0.05** to Selector p-values across the fixed Discovery-nominated ordinary/shared candidate family.

Conditional on the Discovery-nominated family and valid Selector p-values, Holm provides strong family-wise error control under arbitrary dependence.

### 11.2 Localized role discovery

Per-client role construction is exploratory, not a final structural claim. Within a localized candidate, apply **Benjamini-Hochberg at q_role = 0.10** to Discovery client-level partial-test p-values.

This rule is intentionally high recall. No final significance claim is attached to BH role membership.

### 11.3 Final localized certification

Apply **Holm step-down correction at alpha_dev = 0.05** to Probe p-values across the frozen set of localized hypotheses passed from Discovery+Selector.

The final accepted localized set is a subset of Holm rejections after deterministic sign, role-benefit, pair-invariance, and outside-role safety filters. Because the operational set is a subset of Holm rejections, these additional filters cannot increase the probability that at least one false localized hypothesis is accepted.

No family-specific, noise-specific, seed-specific, or retrospectively selected alpha/q values are permitted.

## 12. Shared-Core Re-certification (SCR)

The v11 ordinary/core anchor is no longer immutable.

### 12.1 Discovery-nominated ordinary family

The ordinary candidate family contains:

- intercept `1`;
- ordinary terms in the v6 Discovery selector structure; and
- ordinary terms in the v6 Discovery high-recall bank.

Exception/gated terms are not promoted into the ordinary shared family.

The candidate family is frozen before Selector is inspected.

### 12.2 Selector certification

On Selector:

1. construct the pooled joint ordinary candidate model from additive sufficient statistics;
2. for each non-intercept candidate `t`, compare the joint FULL model with the corresponding REDUCED model that removes only `t`;
3. compute the one-degree-of-freedom partial nested F p-value when identifiable;
4. apply Holm `alpha_shared = 0.05`;
5. retain the intercept and Holm-rejected non-intercept candidates.

### 12.3 Exact predecessor capacity semantics

The frozen predecessor calls v6 with `max_terms = 6`, and v6 explicitly enumerates at most `max_terms - 1` non-intercept bank terms because the intercept is part of the structure.

Therefore Phase-3 SCR preserves the exact shared capacity as:

- **maximum shared structure size = 6 total terms including intercept**;
- therefore **maximum 5 non-intercept shared terms**.

If more than five non-intercept terms survive Holm, retain the five smallest Holm-adjusted p-values, with canonical catalog order as the final deterministic tie-breaker. This is a structural capacity rule, not a result-dependent threshold.

### 12.4 Shared refit

After shared structure is fixed on Selector, refit its coefficients on Discovery+Selector only for the operational shared reference used by later Discovery role analysis and Selector screening.

Probe remains untouched.

The structure selected by Selector cannot be changed by later localized evidence.

## 13. Noise-Calibrated Effect Evidence (NCEE)

### 13.1 Localized candidate provenance

A localized candidate must:

- exist in the frozen grammar;
- have a declared `source_term`;
- satisfy weak structural heredity because the source is either in the SCR shared structure or in the Discovery high-recall bank.

A banked source may remain provenance-only. It is not automatically inserted globally.

### 13.2 Discovery role construction

After SCR has frozen shared structure, return to Discovery for exploratory role construction.

For each localized candidate and each client:

1. construct that client's REDUCED shared model and FULL shared-plus-candidate model;
2. estimate nuisance shared coefficients separately in FULL/REDUCED;
3. compute the client-level partial nested F p-value when the candidate increases rank by one;
4. record the candidate coefficient sign from FULL;
5. apply BH `q_role = 0.10` across eligible clients for that candidate.

BH-supported clients form the provisional role.

### 13.3 Estimability guard

A client may participate in role discovery only when all are true:

- the candidate has positive observed support;
- FULL increases effective rank by exactly one;
- residual degrees of freedom are at least `5`;
- the candidate has at least `10` active Discovery rows.

The active-row floor is a conservative engineering guard fixed prospectively for Phase 3. It is not described as mathematically equivalent to the predecessor five-fold `8 train + 2 held-out` rule and it must not be tuned from Phase-1/Phase-2 outcomes.

A future external-data protocol may replace this guard only through a separately frozen design amendment made before external outcomes are inspected.

### 13.4 Role admissibility

A provisional role is admissible only when:

- at least one client is BH-supported;
- at least one outside-role client remains;
- role size is at most half of all clients;
- supported candidate coefficients have a common nonzero sign under the global numerical sign tolerance.

Mixed-sign or sign-indeterminate roles are classified `SCOPE-SIGN-AMBIGUOUS` and rejected.

If more than half the clients are supported, classify the candidate `GLOBAL-SCOPE-AMBIGUOUS`; Phase 3 does not reinterpret a gated exception as an ordinary shared term.

### 13.5 Frozen role hypothesis

For an admissible role, freeze before Selector localized screening:

- term;
- source;
- role client IDs;
- outside client IDs;
- Discovery effect sign.

The role cannot change after Selector or Probe outcomes are observed.

## 14. Selector localized screening

Selector performs non-final safety/power screening for the frozen role.

For each candidate:

1. compute a role-scope partial nested F test as a diagnostic;
2. require Selector candidate coefficient sign to match the Discovery sign;
3. require median role-client raw SSE gain `SSE_R - SSE_F` to be positive;
4. require pair/structure invariance;
5. require Selector aggregate outside-role non-degradation using the inherited `1e-10` SSE tolerance;
6. reject rank-ambiguous or non-estimable hypotheses.

The Selector p-value is recorded but is not itself a final alpha-level structural claim. A hypothesis that fails any Selector safety condition is not sent to Probe.

## 15. Probe final localized certification

For every localized hypothesis surviving Discovery+Selector:

1. use Probe only;
2. fit the role-scope REDUCED shared model and FULL shared-plus-candidate model from Probe sufficient statistics;
3. require FULL to increase effective rank by exactly one;
4. compute the proper one-degree-of-freedom partial nested F p-value;
5. apply Holm `alpha_dev = 0.05` across all surviving localized hypotheses in that condition;
6. require Probe coefficient sign to match the frozen Discovery sign;
7. require median role-client Probe raw gain to be positive;
8. require Probe outside-role non-degradation using the inherited `1e-10` tolerance;
9. require structural pair invariance.

Only Holm-rejected hypotheses satisfying every deterministic safety filter are operational localized deviations.

Probe cannot create a new candidate, change a role, or change the shared structure.

## 16. Final structure and refit

The final structure is the union of:

- SCR-certified shared terms; and
- Probe-certified localized deviations.

Retain the predecessor high-level capacities:

- maximum shared structure: `6` total terms including intercept;
- maximum operational localized deviations: `2`;
- maximum final structure: `10` total terms including intercept.

If multiple accepted localized deviations share one source, source ambiguity rejects that source-linked localized set.

If more than two localized deviations would be operational, global ambiguity rejects the newly proposed localized set rather than selecting terms by benchmark outcome.

After structure is frozen, refit numerical coefficients using the predecessor final-refit policy on the training information permitted by the study harness. Final coefficient quality may not alter structural acceptance.

## 17. Theoretical targets

### Theorem A: centralized equivalence of federated least squares

For a fixed ordered term set and deterministic rank convention, summing client `X^T X`, `X^T y`, `y^T y`, and `n` yields the same pooled least-squares coefficients, effective rank, and minimized SSE as centralized row concatenation up to floating-point summation error.

### Theorem B: centralized equivalence of partial nested F statistics

Under the same fixed FULL/REDUCED structures and scope, federated aggregate sufficient statistics produce the same partial nested F statistic and p-value as centralized concatenation, up to floating-point error.

### Proposition C: independent shared certification

Conditional on the Discovery-nominated ordinary candidate family, Selector outcomes are not used in candidate nomination. Under valid Selector null p-values, Holm at `alpha_shared` strongly controls family-wise error for the tested shared family.

### Proposition D: independent Probe localized certification

Conditional on the entire Discovery+Selector hypothesis-construction pipeline, Probe is untouched when the localized candidate family, role IDs, and expected signs are fixed. Under valid Probe null p-values, Holm at `alpha_dev` strongly controls family-wise error for the tested localized family.

### Proposition E: post-Holm safety filtering

Because final localized acceptances are a subset of Holm rejections, deterministic post-Holm filtering cannot increase the probability of at least one false final localized acceptance.

### Proposition F: empirical outside-role non-degradation

For each accepted localized deviation, the recorded Selector and Probe checks establish that aggregate FULL SSE does not exceed REDUCED SSE by more than `1e-10` on the recorded outside-role clients. This is an empirical held-out property, not a population-level guarantee.

### Claim boundary

The theoretical error-control claims apply to valid p-values under the stated benchmark noise/model assumptions and fixed data-use sequence. They are not automatically transferred to arbitrary heteroskedastic or dependent real-world noise. External-data validation must report assumption robustness separately.

## 20. Engineering-before-science rule

Phase 3 is separated into two implementation epochs.

### Phase 3A: refactor/parity

No new scientific behavior.

- extract reusable packet/statistic code;
- cache deterministic quantities;
- preserve v11 structural decisions exactly;
- verify the old source tests;
- verify centralized/federated numerical equivalence on deterministic examples;
- use only deterministic fixtures and engineering seed `29001`.

No spent development seed is regenerated.

### Phase 3B: v12 scientific implementation

Only after Phase-3A parity is sealed:

- implement SCR;
- implement NCEE;
- implement sequential Selector/Probe certification;
- implement Holm/BH procedures;
- implement Phase-3 diagnostics and ablations.

This separation ensures that a changed scientific result cannot be attributed ambiguously to refactoring.

## 21. Safe performance optimization

Mandatory optimizations may be implemented only after parity tests exist:

- build partitions/folds/packets once per condition;
- cache client-level Gram/cross-response/SSE/rank quantities;
- reuse cached model fits for nested comparisons;
- avoid rebuilding candidate-invariant packets inside candidate loops;
- separate method runtime from checkpoint/report generation;
- use atomic per-condition checkpoints and periodic consolidated CSVs.

No optimization is accepted only because it is faster. It must first pass regression and centralized-equivalence tests.
